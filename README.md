# Agentic RAG Course Assistant

An agentic Retrieval-Augmented Generation (RAG) system designed to serve as a course teaching assistant and FAQ agent, answering student questions using relevant course materials.

**Status:** Work in progress 🚧

## Getting Started

This project uses [uv](https://docs.astral.sh/uv/) for dependency and project management.

```bash
# Install dependencies
uv sync

# Run the project
uv run <entrypoint>
```
